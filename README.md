Pet owners use the Flutter mobile application to register, manage their pets, and book appointments. Clinic staff, including veterinarians and receptionists, use the ASP.NET web application to view and manage appointments and client and pet information according to their roles. Both applications communicate with the shared Supabase backend, which provides authentication, database storage, and file storage. This allows information such as bookings and pet details to be shared between the mobile and web applications, creating one integrated system.

### Lecturer login
1. Open the staff web app URL provided by the team.
2. Go to **Login**.
3. Sign in with the **lecturer demo account** (email: mistakukku@necub.com Password: Lecture@01).
4. You should reach the dashboard.
5. Then after they can log out , register an account using their own preferred email where they will receive the confirmation email to confirm their account.
6. Next they can log in back with their demo account & go to settings and type in the email of the new account they created and give it Staff access of their choosing.
7. Then the next time they log in they can use the newly registered account as it will be now able to login to the respective role assigned.
